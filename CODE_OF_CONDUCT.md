# Contributor Covenant Code of Conduct

## Our standard

We are committed to a respectful, harassment-free community. Be considerate,
assume good intent, give actionable feedback, and avoid sharing private
information about candidates, recruiters, or companies.

## Scope

This code applies to issues, pull requests, discussions, and other project
spaces.

## Enforcement

Report unacceptable behavior privately to the project maintainers. Maintainers
may remove content or restrict participation when behavior threatens a safe and
productive project environment.

This project follows the spirit of the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
